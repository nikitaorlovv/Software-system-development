🎯 О программе

Программа сортирует массивы целых чисел с помощью алгоритма Bitonic Sort (Битонная сортировка).

✏️ Ручной ввод массива

Введите числа в текстовое поле. Поддерживаются форматы:

  • Через запятую: 5,3,8,1,9
  • Через пробел: 5 3 8 1 9
  • В столбик: 5
    3
    8
  • Смешанный формат: 5, 3 8,1 9

🎲 Генерация случайного массива

  • От/До - диапазон значений элементов
  • Количество - размер массива (1-1000)
  • Нажмите "Сгенерировать" - массив появится в поле ввода

📁 Загрузка из файла

  • Поддерживаются файлы .txt
  • Числа в файле могут быть разделены пробелами, запятыми или переносами строк
  • Пример содержимого файла: 10 20 30 40 50

💾 Сохранение в историю

  • После сортировки нажмите "Сохранить в историю"
  • Все сохранённые массивы привязаны к вашему аккаунту
  • Историю можно просмотреть по кнопке "Загрузить историю"

⚡ Алгоритм Bitonic Sort

  • Временная сложность: O(n log² n)
  • Параллельный алгоритм сортировки
  • Хорошо подходит для аппаратной реализации
